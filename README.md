## 📊 Proyectos de Analista de Datos BI

### 1. RappiPlus: de datos a decisiones de negocio
*Proyecto del Bootcamp TripleTen (2026)*

**Descripción:** Entender el desempeño del servicio y detectar oportunidades concretas de mejora.

**Habilidades destacadas:** Python, SQL, flujo de trabajo analítico y visualización de datos con Tableau.

- Recopilé, revisé, limpié y estructuré grandes conjuntos de datos usando Python y SQL para apoyar el análisis del negocio.
- Analicé si el negocio era rentable (KPIs principales: revenue, costo total, marketing y rentabilidad).
- Analicé el comportamiento de ventas (ticket promedio, cantidad promedio, producto más vendido y marketing por canal).
- Identifiqué dónde se pierden los usuarios (funnel de conversión).
- Evalué la retención de cohortes.
- Validé si los cambios generaron impacto (experimentación A/B).
- Comuniqué los resultados en dashboards interactivos en Tableau, visualizando el análisis de ventas, costos, marketing y conversión.
- Documenté los hallazgos, presenté las métricas principales, los insights accionables, las recomendaciones estratégicas y las limitaciones.
